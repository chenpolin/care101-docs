# Welcome 療育雲助手

**療育雲助手**是一款專門為語言治療所、心理治療所、職能治療所設計的管理系統，旨在簡化治療所的行政工作流程，提升工作效率，讓治療師和經營者能夠專注於個案的治療和服務。

### **主要功能**

1. **個案管理**：提供全面的個案資料管理功能，包含新增、修改、查詢和匯出個案資料，並可設定綜合報告提醒，確保治療進度不被遺漏。
2. **預約管理**：有效管理治療所的預約流程，包括課程的查詢、新增、修改，以及治療紀錄的管理，讓預約和課程調度更加靈活。
3. **帳務與發票管理**：幫助治療所輕鬆管理帳務報表與收據的產生和設定，確保財務紀錄清晰完整，並能下載早療個案資料以供報表使用。
4. **系統設定與管理**：支持治療師班表、營業時間、診斷標籤等設置，並提供系統公告訊息的發布功能，讓整個治療所的運作更有條理。

### **解決的問題**

* **預約衝突與排程困難**：透過自動化的預約系統，幫助解決治療師班表和教室排程的衝突，確保每個預約都能順利安排。
* **資料管理混亂**：集中管理個案資料、治療紀錄、帳務和發票，減少紙本資料的冗雜性，降低出錯的機率。
* **財務管理困難**：系統自動生成的帳務報表和收據，有助於快速追蹤治療所的收入和支出，提升財務管理的效率。

透過這套系統，治療所的日常運營能夠更加流暢，管理者可以輕鬆掌握整體業務狀況，並進一步改善治療所的服務品質。
