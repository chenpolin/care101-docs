# D1-5 治療師LINE設定

**為什麼需要設定治療師？**

* 確保治療師能正常接收 LINE 通知
* 管理治療師的 LINE 連線狀態
* 追蹤治療師的通知接收情況



**前置準備**：

1. 治療師必須先加入診所的 LINE Bot 為好友
   * 向診所經理或管理員取得 LINE Bot 的 QR Code 或連結
   * 使用 LINE App 掃描 QR Code 或點擊連結
   * 加入 LINE Bot 為好友

**操作步驟**：

1. **登入系統**
   * 使用治療師帳號登入系統
2. **進入「我的設定」頁面**
   * 左側選單 → 「我的設定」
3. **找到「LINE ID」設定區塊**
   * 在「我的設定」頁面中，找到「LINE 通知設定」區塊
4. **填寫 LINE User ID**
   * 在點擊 「透過LINE login取得」 按鈕，會開啟LINE進行驗證和授權
   * 最後會取得**LINE User ID，**&#x4F8B;如：`U1234567890abcdef1234567890abcdef`
5. **確認連線狀態**
6. **測試連線**
   * 點擊「測試連線」或「驗證」按鈕
   * 系統會發送測試訊息到治療師的 LINE
   * 確認收到測試訊息後，表示設定成功
