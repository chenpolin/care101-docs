# D1-3 LINE 官方帳號創建及費用

**適用對象**：診所經理

**為什麼需要 LINE 官方帳號？**

* LINE 官方帳號是診所與個案、治療師溝通的重要管道
* 透過 LINE 官方帳號可以發送預約提醒、通知等重要訊息
* 提供更好的客戶服務體驗

***

**LINE 官方帳號類型**

**免費版（Basic）**：

* **費用**：免費
* **功能限制**：
  * 每月可發送訊息數量有限 (200則/月)
  * 無法使用進階功能（如：Rich Menu、圖文訊息等）
  * 適合初期使用或訊息量較少的診所

**付費版（Premium）**：

* **費用**：依方案而定（通常為月費制）
* **功能優勢**：
  * 無限制發送訊息（或更高的發送額度）
  * 可使用進階功能
  * 提供更好的數據分析
  * 適合訊息量較大或需要進階功能的診所

***

**創建 LINE 官方帳號**

**操作步驟**：

1. **前往 LINE Official Account Manager**
   * 開啟瀏覽器，前往 [LINE Official Account Manager](https://manager.line.biz/)
   * 或搜尋「LINE 官方帳號管理後台」
2. **註冊帳號**
   * 點擊「註冊」或「建立帳號」
   * 選擇註冊方式（Email 或電話號碼）
   * 填寫基本資料並完成註冊
3. **建立官方帳號**
   * 登入後，點擊「建立官方帳號」
   * 選擇帳號類型（免費版或付費版）
   * 填寫診所基本資料：
     * 診所名稱
     * 診所類別
     * 診所簡介
     * 聯絡資訊
4. **完成設定**
   * 上傳診所 Logo 或頭像
   * 設定歡迎訊息
   * 完成基本設定
5. **取得 LINE Bot 資訊**
   * 在管理後台取得：
     * Channel ID
     * Channel Secret
     * Channel Access Token
   * 這些資訊需要提供給系統管理員進行系統整合

**6.4.2 官方帳號發信設定**

**適用對象**：診所經理、管理員

**為什麼需要設定發信？**

* 正確的發信設定可以確保通知能正常發送
* 避免訊息被標記為垃圾訊息
* 提供更好的發送效果

***

**與系統整合設定**

**操作步驟**：

1. **取得 API 資訊**
   * 在 LINE Official Account Manager 中取得：
     * **Channel ID**：官方帳號的識別碼
     * **Channel Secret**：官方帳號的密鑰
     * **Channel Access Token**：存取權杖（用於發送訊息）
2. **提供給系統管理員**
   * 將上述資訊提供給系統管理員
   * 系統管理員會進行系統整合設定
3. **測試整合**
   * 系統整合完成後，測試發送通知
   * 確認通知能正常發送到 LINE

**注意事項**：

* Channel Secret 和 Channel Access Token 屬於敏感資訊，請妥善保管
* 不要將這些資訊分享給未授權的人員
* 如果發現資訊外洩，應立即重新生成

***

**發送量監控**

**操作步驟**：

1. **查看使用量統計**
   * 在 LINE Official Account Manager 中查看「使用量」或「Usage」
   * 查看當月已發送的訊息數量
2. **監控費用**
   * 查看當月產生的費用
   * 確認是否超過預算
3. **優化發送策略**
   * 根據使用量調整發送策略
   * 避免不必要的訊息發送
   * 考慮升級方案以降低成本
