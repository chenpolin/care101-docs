# D1-2 通知設定

**使用情境**：

* 想要調整通知的發送方式
* 想要自訂通知內容
* 想要設定提醒時程

**操作步驟**：

1. **進入通知設定頁面**
   * 左側選單 → 「通知設定」
   * 進入通知設定頁面
2.  **設定提醒時程**

    **診斷書到期提醒**

    * 在「診斷書到期提醒天數」區塊中設定
    * 點擊「+ 新增」按鈕，輸入天數（1-365 天）
    * 可以設定多個提醒時間點（例如：到期前 30 天、到期前 7 天）
    * 系統會在診斷書到期前這些天數發送提醒給個案、治療師與診所

    **綜合評估到期提醒**

    * 在「綜合評估到期提醒天數」區塊中設定
    * 點擊「+ 新增」按鈕，輸入天數（1-365 天）
    * 可以設定多個提醒時間點
    * 系統會在綜合評估到期前這些天數發送提醒

    **治療紀錄撰寫提醒**

    * **首次提醒**：設定預約結束後幾天、幾點發送提醒（提醒對象：治療師）
    * **再次提醒**：設定首次提醒後幾天、幾點再次發送提醒（提醒對象：治療師）
    * **最後提醒**：設定再次提醒後幾天、幾點最後發送提醒（提醒對象：治療師和診所）
3. **設定通知偏好**
   * 在通知事件列表中，選擇要設定的通知類型
   * 針對每個通知類型，可以：
     * 選擇接收對象（個案、治療師、診所）
     * 選擇通知管道（Email、LINE、系統通知）
     * 啟用或停用通知
4. **自訂通知模板**
   * 點擊通知類型展開詳細設定
   * 針對每個接收對象和通知管道，可以：
     * 編輯通知標題（Email 和系統通知）
     * 編輯通知內容
     * 使用變數自訂通知內容（例如：`{{name}}`、`{{clinic_name}}` 等）
5. **儲存設定**
   * 點擊「儲存變更」按鈕
   * 系統會儲存所有設定
6. **重設設定**（選用）
   * 如果需要恢復預設值，點擊「重設」按鈕
   * 確認後會恢復系統預設的通知設定

**注意事項**：

* 通知設定需要管理員權限
* 診所經理角色只能查看設定，無法修改
* 修改設定後，新的通知會使用新設定
* 提醒時程設定會影響所有相關的通知發送



**治療師 LINE ID 設定**

**為什麼需要設定？**

* 治療師需要設定 LINE ID 才能接收 LINE 通知

**操作步驟**：

1. 治療師登入系統
2. 進入「我的設定」頁面
3. 填寫或更新「LINE ID」欄位
4. 儲存設定

**或由診所經理設定**：

1. 進入「設定」頁面 → 「治療師設定」
2. 編輯治療師資料
3. 填寫「LINE ID」欄位
4. 儲存設定

***

**個案 Email 設定**

**為什麼需要設定？**

* 個案需要設定 Email 才能接收 Email 通知

**操作步驟**：

1. 進入「個案」頁面
2. 找到要設定的個案
3. 編輯個案資料
4. 填寫或更新「Email」欄位
5. 儲存設定
