# C2-3 查看特定個案的預約

**使用情境**：

* 個案來電詢問他的預約時間
* 想查看個案的所有預約記錄
* 確認個案的預約狀況

**操作步驟**：

### **方法一：在行事曆頁面搜尋**

1. **進入行事曆頁面**
   * 左側選單 → 「行事曆」
2. **使用個案搜尋**
   * 在左側邊欄找到「個案搜尋」欄位
   * 輸入個案姓名（支援模糊搜尋）
   * 系統會自動過濾並高亮顯示該個案的所有預約
3. **查看預約**
   * 該個案的預約會以**高亮**顯示（通常是黃色邊框）
   * 其他預約會正常顯示
   * 可以點擊預約事件查看詳細資訊

**清除搜尋**：

* 點擊搜尋欄位旁的「×」按鈕
* 或清空搜尋欄位

### **方法二：在預約列表頁面搜尋**

1. **進入預約列表頁面**
   * 左側選單 → 「預約列表」
2. **使用個案名稱搜尋**
   * 在「個案名稱」或「搜尋」欄位輸入個案姓名
   * 可以同時設定其他篩選條件（時間區間、治療師、狀態等）
3. **查看預約列表**
   * 列表會顯示該個案的所有預約
   * 可以查看詳細資訊和預約歷史

**進階功能**：

* 可以從個案資料頁面查看該個案的所有預約記錄
