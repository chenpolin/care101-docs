# C2-1 查看今天的預約

{% embed url="https://youtu.be/8pkVqb1s8Gg" %}

**使用情境**：

* 想快速了解今天有哪些預約
* 準備今天的工作安排
* 確認今天的預約狀況

**操作步驟**：

### **方法一：在行事曆頁面查看**

1. **進入行事曆頁面**
   * 左側選單 → 「行事曆」
2. **點擊「今天」按鈕**
   * 通常位於行事曆上方工具列
   * 系統會自動跳轉到今天
3. **查看當日預約**
   * 行事曆會顯示今天的所有預約
   * 每個預約會顯示：個案名稱、時間、教室
   * 不同狀態的預約會有不同顏色：
     * 準備中：綠色
     * 已完成：藍色
     * 請假：紅色

### **方法二：在預約列表頁面查看**

1. **進入預約列表頁面**
   * 左側選單 → 「預約列表」
2. **設定篩選條件**
   * 在「時間區間」下拉選單中選擇「今日」
   * 點擊「搜尋」或「篩選」按鈕（系統會自動更新）
3. **查看預約列表**
   * 列表會顯示今天的所有預約
   * 可以查看詳細資訊：個案、治療師、時間、教室、課程、狀態等

**進階功能**：

* 可以同時篩選治療師、預約狀態等條件
* 可以點擊預約項目查看詳細資訊
* 可以直接在列表上編輯或刪除預約
