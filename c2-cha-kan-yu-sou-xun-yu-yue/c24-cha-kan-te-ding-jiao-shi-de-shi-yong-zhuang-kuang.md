# C2-4 查看特定教室的使用狀況

**使用情境**：

* 想確認某間教室今天的使用情況
* 教室需要維護，檢查何時有空檔
* 規劃教室使用安排

**操作步驟**：

1. **進入行事曆頁面**
   * 左側選單 → 「行事曆」
2. **設定教室篩選**
   * 在左側邊欄找到「教室篩選」區塊
   * 點擊「▶ 全部教室」展開選單（如果已收合）
   * 選擇要查看的教室
   * 系統會自動更新行事曆
3. **查看使用狀況**
   * 該教室的預約會**正常顯示**
   * 其他教室的預約隱藏
   * 可以清楚看到該教室的使用時段
4. **切換查看其他教室**
   * 選擇「全部教室」恢復正常顯示
   * 或選擇其他教室查看

**適用情境**：

* 教室維護：找出教室的空檔時間
* 設備檢查：確認教室使用狀況
* 規劃安排：了解教室使用情況
