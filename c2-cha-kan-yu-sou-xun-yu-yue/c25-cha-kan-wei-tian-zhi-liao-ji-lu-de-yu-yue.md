# C2-5 查看未填治療紀錄的預約

**使用情境**：

* 找出已完成但還沒填寫治療紀錄的預約
* 補填治療紀錄
* 確認治療紀錄完整性

**操作步驟**：

1. **進入預約列表頁面**
   * 左側選單 → 「預約列表」
2. **設定篩選條件**
   * 在「預約狀態」下拉選單中選擇「未填治療紀錄」
   * 系統會自動更新列表
   * 狀態選項會顯示數量，例如：「未填治療紀錄 (3)」
3. **查看未填治療紀錄的預約**
   * 列表會顯示所有「未填治療紀錄」狀態的預約
   * 通常是狀態為「已完成」但尚未填寫治療紀錄的預約
   * 可以點擊預約項目查看詳細資訊
4. **填寫治療紀錄**
   * 點擊預約項目查看詳細資訊
   * 進入治療紀錄填寫頁面（如果系統有此功能）
   * 填寫治療紀錄後，狀態會自動更新

**注意事項**：

* 「未填治療紀錄」狀態會顯示數量，方便快速了解有多少預約需要處理
* 建議定期檢查並補填治療紀錄
* 治療紀錄的填寫方式可能因系統而異，請參考相關文件
