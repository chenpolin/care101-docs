# C1-2 為個案建立週期性預約

{% embed url="https://youtu.be/I1v3EsKYxco" %}

**使用情境**：

* 個案要連續 8 週，每週同一時間上課
* 個案需要長期療程，每週固定時段
* 為多個個案建立相同的週期預約

**操作步驟**：

1. **進入行事曆頁面**
   * 左側選單 → 「行事曆」
2. **點擊「預約時段」**
3. **設定第一堂的資訊**
   * **治療師**：選擇治療師
   * **日期**：選擇第一堂的日期
   * **時段**：選擇第一堂的開始時間和結束時間
   * **課程**：選擇課程
   * **教室**：選擇教室
   * **個案**：選擇個案（可多選）
   * **時長**：選擇時長
   * **金額**：確認金額
   * **備註**：選填
4. **設定週期參數**
   * **頻率**：通常為「每週」（系統預設）
   * **堂數**：輸入要建立的堂數（例如：`8` 表示連續 8 週）
   * **結束日期**：系統會根據第一堂日期和堂數自動計算
5. **確認週期衝突檢測**
   * 系統會自動檢測每一堂是否會有衝突
   * 顯示檢測結果：
     * 成功：可以建立的堂數
     * 失敗：無法建立的堂數及原因
   * 查看失敗詳情，了解哪些週次無法建立
6. **提交預約**
   * 點擊「確認預約」按鈕
   * 系統會建立所有可以建立的預約
   * 如果部分週次失敗，系統會顯示「成功 X/Y 堂」的訊息
7. **處理失敗的週次**
   * 查看失敗詳情，了解哪些週次無法建立及原因
   * 手動為失敗的週次建立預約（選擇其他時段或調整設定）

**注意事項**：

* 週期預約會自動檢查每一堂的衝突
* 如果某些週次有衝突（例如：治療師已有其他預約、教室已被預約），該週次會跳過
* 系統會顯示「成功 X/Y 堂」的訊息，告知您哪些週次成功建立，哪些失敗
* 失敗的週次需要手動建立預約

**常見失敗原因**：

* 該週次治療師已有其他預約
* 該週次教室已被其他預約使用
* 該週次不在營業時間內
* 該週次不在治療師服務時間內

**範例**：

```
建立 8 週的週期預約：
- 第一堂：2025/01/15（週三）10:00-11:00
- 頻率：每週
- 堂數：8

系統檢測結果：
- 成功：6 堂（第 1、2、3、4、6、8 週）
- 失敗：2 堂（第 5、7 週）

失敗原因：
- 第 5 週：治療師已有其他預約
- 第 7 週：教室已被其他預約使用

處理方式：
- 手動為第 5、7 週建立預約，選擇其他時段
```
