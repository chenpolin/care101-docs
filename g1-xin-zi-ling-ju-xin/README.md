# G1-薪資領據(新)

### 📋 前言：進入方式與事前準備

在建立任何薪資單之前，必須確保系統中已完成基本的薪資設定。

1. **進入選單**：從系統左側的主選單欄位，點選並進入「薪資領據」頁面。
2. **基本確認**：確認各治療師的薪資範本與拆分比例已設定完畢，以利系統自動進行準確的佣金計算。

***

### 📌 第一章：建立薪資單

本章節介紹如何為治療師建立一般的薪資單，並檢視其詳細內容、訂單清單及津貼代扣設定。

#### 🛠️ 操作步驟

1. **新增薪資單**：點選頁面右上方的「建立薪資單」按鈕。
2. **選擇條件**：
   * 選擇要進行結算之「治療師」。
   * 選擇「結薪月份」（例如：6 月），系統會自動帶出對應的結薪開始日與結束日。
3. **建立草稿**：在此步驟先不勾選任何進階條件，直接點擊「建立薪資單」按鈕，建立一筆獨立的「草稿」狀態薪資單。
4. **檢視詳情**：在列表中點擊「檢視」進入詳情頁面，上方將呈現治療師基本資料與處理進度（共 5 個進度階：草稿 ➔ 待簽收 ➔ 已簽收 ➔ 已發放 ➔ 歸檔完成）。
5. **確認結薪課程清單**：
   * **當月課程**：呈現符合「收款狀態已收款」且「訂單狀態已完成」的當月訂單，並可追溯佣金來源。
   * **歷史補發**：系統會自動追溯先前未結算但目前已達成「已收款＋已完成」狀態的歷史訂單，並同步納入本次結薪。
6. **處理待處理課程**：
   * 待處理清單包含未同時符合「已收款」與「已完成」的訂單（如：已收款但狀態準備中、未收款且準備中、已完成但未收款）。
   * 對於「已收款但準備中」的訂單，可直接在清單中手動切換為「已完成」，使該筆訂單即刻轉入本次結薪清單。
   * 對於「已完成但未收款」的訂單，需由人工核對對帳狀態。
7. **編輯額外津貼與代扣項目**：
   * **額外津貼**：點擊「編輯津貼」，可手動新增教育補助、演講費等項目，並選擇是否因稅。
   * **代扣項目**：依據因稅基數，勾選後自動計算代扣稅額及二代健保補充保費。
8. **發布薪資單**：確認下方統計（課程佣金、額外津貼、代扣稅額、實領金額）無誤後，點擊「發布」，薪資單狀態即轉為「待簽收」。

Tip

歷史補發功能為全自動檢查，所長無須擔心遺漏任何過去因狀態未完成而未發放的課程費用。

### 📌 第二章：排除補助款

本章節介紹在建立薪資單時，如何啟用進階排除條件，將政府補助款尚未到帳的訂單排除於本次結算之外。

#### 🛠️ 操作步驟

1. **建立並啟用進階條件**：建立薪資單時，選擇治療師與月份（例如：7 月），並將「排除等待補助的訂單」開關開啟。
2. **生成排除清單**：建立後進入檢視，系統會自動檢查並把政府補助款尚未入帳的訂單排除，列於下方的「排除的課程清單」中並加上備註。
3. **僅結算全額完成訂單**：此時只有「部分負擔」與「政府補助款」皆已足額到帳（狀態為全額完成）的訂單才會納入結算。
4. **跨月自動補入**：下個月建立薪資單時，系統會自動檢查這些被排除訂單的補助款是否到帳，一旦到帳，將自動納入下個月的結算中。

***

### 📌 第三章：排除無紀錄

本章節介紹如何啟用排除未繳交治療紀錄之訂單的進階條件，以督促治療師按時繳交病歷與治療紀錄。

#### 🛠️ 操作步驟

1. **啟用未交紀錄排除**：建立薪資單時（例如：8 月），開啟「排除未繳交治療紀錄的訂單」開關。
2. **檢視排除清單**：建立完成後，凡是收款與訂單狀態皆已完成、但「治療師尚未完成並提交治療紀錄」的訂單，均會被列入排除課程清單，且備註說明原因。
3. **發布結算**：僅有確實完成治療紀錄的訂單會被計入。確認無誤後即可點選「發布」。

***

### 📌 第四章：治療師簽收

本章節為治療師端的操作步驟，說明如何核對並確認簽收所長發布的薪資單。

#### 🛠️ 操作步驟

1. **登入與查閱**：治療師登入個人帳號後，前往「薪資領據」頁面。
2. **核對明細**：在列表中可查看到處於「待簽收」狀態的薪資單（如 6 月、7 月、8 月），點擊「檢視詳情」仔細核對核發的佣金與明細。
3. **確認簽收**：確認金額與明細無誤後，點擊「確認簽收」按鈕，薪資單進度即會同步變更為「已簽收」。

***

### 📌 第五章：撥款與發放

本章節為所長端的操作步驟，說明如何在治療師簽收後，進行出款、備註與歸檔。

#### 🛠️ 操作步驟

1. **發放撥款**：當薪資單經治療師簽收變為「已簽收」狀態後，所長即可點擊進行「撥款」。
2. **選擇付款帳號**：可從付款下拉選單中選擇出款帳戶（此帳戶與系統的記帳管理直接聯動，例如選擇「帳號 A」）。
3. **填寫備註與上傳證明**：填寫撥款相關備註，或上傳銀行匯款成功之圖片截圖。
4. **完成歸檔**：點擊確認送出後，薪資單狀態變更為「已發放」，即完成本期薪資發放作業。治療師隨後亦可在其帳號端檢視付款證明圖片與細節。
