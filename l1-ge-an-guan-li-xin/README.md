# L1-個案管理(新)

### 📋 進入個案管理

1. 以**所長或治療師帳號**登入雲助手。
2. 進入左側選單的**個案管理**頁面。
3. 本教學將依序介紹：個案列表、基本資料、治療紀錄、預約紀錄、點數帳戶、額外欄位設定、欄位可見度。

***

### 📌 第一章：個案管理列表

個案管理列表提供快速搜尋與篩選，協助所長與治療師掌握個案狀態。

#### 🛠️ 搜尋個案

1. 進入**個案管理**頁面。
2. 在上方**搜尋欄位**直接輸入個案姓名。
3. 系統會自動定位並顯示該個案的基本資訊。

#### 🛠️ 篩選個案

1. 使用**篩選**功能選擇特定**治療師**，即可列出該治療師負責的個案。
2. 可進一步依**個案狀態**篩選，例如：服務中、待排、已畢業。
3. **待排**個案會顯示**紅色標籤**；若右上角出現逾期待排提醒，請通知**診所經理**處理。

Tip

待排個案代表尚未正式排入服務，建議定期檢視右上角提醒，避免個案等候過久。

***

### 📌 第二章：基本資料

點選個案後可進入資料頁面，檢視與編輯個案完整資訊。

#### 🛠️ 分頁說明

個案資料頁面包含以下分頁：

| 分頁       | 說明                   |
| -------- | -------------------- |
| **基本資料** | 姓名、生日、電話、Email 等固定欄位 |
| **治療紀錄** | 過往治療與問卷紀錄            |
| **預約紀錄** | 課程預約與安排狀況            |
| **諮商項目** | 相關諮商項目資訊             |
| **點數帳戶** | 預儲點數與扣款紀錄            |

#### 🛠️ 固定與額外欄位

1. 下方**固定欄位**包含生日、電話、Email 等基本資料。
2. **額外欄位**可依各治療所需求自行增設（例如緊急聯絡人、特殊備註等）。
3. 各所可增設多個自訂欄位，並於此頁面填寫。

#### 🛠️ 編輯與其他操作

1. 點選右上角**編輯**，可登打或修改個案資料。
2. 若看不到基本資料，可能是**權限**未開啟，請聯絡所長調整。
3. 具備權限者可使用**刪除**、**下載**個案基本資料等功能（依帳號權限顯示按鈕）。

***

### 📌 第三章：治療紀錄

治療紀錄彙整個案過往所有治療與問卷填寫結果。

#### 🛠️ 操作步驟

1. 進入個案資料頁，切換至**治療紀錄**分頁。
2. 系統會列出該個案全部治療紀錄。
3. 可選擇**特定日期區間**檢視紀錄。
4. 若個案曾填寫特殊問卷（例如 **BSRS-5 簡式健康量表**），也會統整顯示於此。
5. 可從此頁**下載填表結果**。

***

### 📌 第四章：預約紀錄

預約紀錄用於查閱個案過去與未來的課程安排。

#### 🛠️ 操作步驟

1. 切換至**預約紀錄**分頁。
2. 使用**區間篩選**查閱特定期間的預約。
3. 可檢視**過去課程**、**未來課程**及目前**課程安排狀況**。

***

### 📌 第五章：點數帳戶

點數帳戶供個案預先儲值，完成課程後以點數支付費用。

#### 🛠️ 操作步驟

1. 切換至**點數帳戶**分頁。
2. 所長可使用**儲值**按鈕為個案儲值。
3. 適用於個案預先儲存金額的情境：以**點數**形式存放於帳戶，完成課程後以點數支付。

Important

儲值與扣點操作通常限**所長**權限，請依診所內部規範使用。

***

### 📌 第六章：額外欄位設定

若需在個案基本資料中新增自訂欄位，請至設定頁面進行設定。

#### 🛠️ 操作步驟

1. 進入**設定**頁面 → **個案資訊的欄位設定**。
2. 捲至最下方找到**個案額外欄位**區塊。
3. 點選**新增** → 輸入**欄位名稱**（例如：緊急聯絡人電話）。
4. 選擇**欄位類型**：單行文字、多行文字、數字、下拉選單、單選、複選等。
5. 設定為**必填**（若需要）後**送出**。
6. 可使用右側**向上**按鈕調整欄位顯示順序（例如放在緊急聯絡人下方）。

Tip

新增欄位後，系統需短暫時間更新；個案資料表不會立即出現新欄位，請稍候再重新整理。

***

### 📌 第七章：欄位可見度

欄位可見度設定可控制治療師能看見哪些個案資料，保護敏感資訊。

#### 🛠️ 操作步驟

1. 於設定頁面進入**個案欄位可見度**權限設定。
2. 欄位分為：**基本欄位**、**額外欄位**、**自訂欄位**。
3. 勾選要讓**治療師**看見的欄位。
4. 若需隱藏敏感資料，可僅開放：病歷號碼、專責治療師、ID、診斷、狀態等必要欄位。
5. 勾選完成後**儲存設定**。

Important

完成設定後，治療師登入僅能看到已勾選的欄位，可避免接觸電話、地址等敏感個資。
