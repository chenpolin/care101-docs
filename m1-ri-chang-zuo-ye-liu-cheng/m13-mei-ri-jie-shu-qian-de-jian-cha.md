# M1-3 每日結束前的檢查

**使用情境**：

* 每天結束工作前，確認所有預約都已正確處理
* 準備明天的工作

**檢查項目**：

1. **確認所有預約狀態**
   * 進入預約列表頁面
   * 查看今天的預約
   * 確認所有預約狀態是否正確（已完成、請假等）
2. **檢查未填治療紀錄**
   * 篩選「未填治療紀錄」狀態
   * 補填治療紀錄
3. **查看明天的預約**
   * 進入行事曆頁面
   * 查看明天的預約
   * 提前準備明天的安排
4. **確認收款狀況**
   * 進入帳務中心
   * 查看今天的收款狀況
   * 確認所有收款都已記錄

**建議流程**：

1. 確認今天所有預約狀態
2. 補填治療紀錄
3. 確認收款狀況
4. 查看明天預約，提前準備
