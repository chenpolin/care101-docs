# C3-3 修改週期預約

### 修改週期預約的單一堂課

**使用情境**：

* 週期預約中某一堂需要調整時間或資訊
* 某一堂個案請假，需要調整
* 只修改單一堂，其他堂次不變

**操作步驟**：

1. **找到要修改的預約**
   * 在行事曆上找到該堂預約事件
   * 或在預約列表中找到該預約項目
2. **開啟編輯功能**
   * 點擊預約事件或項目
   * 點擊「編輯」按鈕
3. **選擇更新範圍**
   * 系統會詢問：「要更新單一堂還是整個系列？」
   * 選擇「只更新這一堂」或「單次更新」
4. **修改資訊**
   * 可以修改：時間、教室、課程、金額、備註等
   * 修改方式與一般預約相同（見 4.1、4.2）
5. **儲存修改**
   * 點擊「儲存」或「確認」按鈕
   * 系統會只更新這一堂預約，其他堂次不受影響

**注意事項**：

* 只會影響這一堂預約
* 其他堂次保持不變
* 系統會檢查修改後的時段是否有衝突

**適用情境**：

* 某一堂個案請假，需要調整時間
* 某一堂需要換教室
* 臨時調整單一堂的設定



### 修改整個週期預約系列

**使用情境**：

* 週期預約需要整體調整（例如：換教室、換課程）
* 從某一週開始，後續所有預約都需要調整
* 批量更新週期預約

**操作步驟**：

1. **找到要修改的預約**
   * 在行事曆上找到週期預約中的任一堂
   * 或在預約列表中找到該預約項目
2. **開啟編輯功能**
   * 點擊預約事件或項目
   * 點擊「編輯」按鈕
3. **選擇更新範圍**
   * 系統會詢問：「要更新單一堂還是整個系列？」
   * 選擇「更新整個系列」或「系列更新」
4. **選擇更新起始點**
   * 系統會詢問：「要從第幾週開始更新？」
   * 選擇起始週次（例如：從第 3 週開始）
   * 第 3 週之前的預約不會被修改
5. **修改資訊**
   * 可以修改：教室、課程、金額、備註等
   * **注意**：時間通常無法批量修改（需要逐堂調整）
6. **確認修改**
   * 系統會顯示確認訊息，說明會影響哪些預約
   * 確認後點擊「儲存」或「確認」按鈕
7. **查看更新結果**
   * 系統會更新從起始週次開始的所有後續預約
   * 可以查看更新後的預約確認是否正確

**注意事項**：

* 會影響從起始週次開始的所有後續預約
  * 例如：從第 3 週開始更新，第 3、4、5、6... 週都會被更新
* 起始週次之前的預約不會被修改
* 系統會檢查每一堂更新後是否有衝突
* 如果某些週次有衝突，該週次可能無法更新

**適用情境**：

* 週期預約需要整體換教室
* 週期預約需要調整課程或金額
* 從某一週開始，後續預約都需要調整

**範例**：

```
原始週期預約（8 週）：
- 第 1-8 週：教室 A、課程 X

修改操作：
- 選擇「更新整個系列」
- 選擇「從第 3 週開始」
- 修改為：教室 B、課程 Y

結果：
- 第 1-2 週：保持不變（教室 A、課程 X）
- 第 3-8 週：已更新（教室 B、課程 Y）
```
